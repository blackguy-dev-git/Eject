# Eject

Eject is a social media web application project currently under development. The project focuses on building a clean, modern frontend, with backend functionality planned and currently in progress.

## 🚀 Current Status

- ✅ Frontend completed
- ✅ HTML and CSS
- 🚧 Backend under development
- ⏳ User authentication and account management
- ⏳ Post creation and feed functionality
- ⏳ Database integration

## 🖥️ Frontend

The frontend is built using:

- **HTML5** — page structure and content
- **CSS3** — styling, layout, and visual design

The frontend provides the foundation for Eject's user interface. Backend integration will make its features functional.

## ⚙️ Backend (In Progress)

The backend is being developed using:

- **Python** — application logic
- **FastAPI** — API development and request handling
- **SQLite** — database storage

Planned backend features include:

- User registration and login
- Secure password handling
- Creating and displaying posts
- Database integration
- Connecting the frontend to the backend through API requests

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Frontend structure |
| CSS3 | Frontend styling |
| JavaScript | Planned frontend-backend communication |
| Python | Backend logic |
| FastAPI | REST API |
| SQLite | Database |

## 📌 Project Goals

Eject is a learning and development project focused on building a full-stack web application while developing practical skills in frontend development, backend engineering, API design, and database management.

## 📍 Development

The frontend is complete, and backend development is currently underway. Features will be implemented and integrated progressively.
